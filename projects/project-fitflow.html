FitFlow: Health & Fitness Platform

Full-stack web app · MySQL schema · Flask API · Streamlit prototype

FitFlow is a health and fitness platform designed to connect clients, trainers, analysts, and system administrators in one system. Instead of scattered spreadsheets and ad-hoc messages, it provides a structured way to manage workouts, programs, and health data end to end.

Our team started from the database layer up: defining user personas, creating localized and global ER diagrams, and designing a relational schema that supports role-based access. We implemented the schema with SQL DDL, generated realistic sample data, and wrote core queries for each role to answer questions about progress, usage, and system health.

On top of the database, we designed a REST API and built a prototype using Flask and Streamlit. The app lets admins manage accounts and backups, trainers assign and monitor programs, clients log workouts and view streaks, and analysts explore trends in health metrics.

Project details

  • Course: CS3200 – Database Design
  • Role: schema design, SQL DDL, core queries, API matrix
  • Tech: MySQL, SQL, Flask API, Streamlit UI
  • Focus: multi-role fitness system (admin, trainer, analyst, client)
